1. Pourquoi Notre Solution est Supérieure : Normes & Avantages Clients

Le LMS Manjary Soa a été conçu selon les standards les plus stricts de l'industrie logicielle pour les établissements d'enseignement et les caisses décentralisées :

⚡ Architecture Local-First (100% Fonctionnel Sans Internet)

Contrairement aux logiciels purement web qui deviennent inutilisables dès que la connexion 4G/Fibre coupe, le LMS s'exécute sur le moteur SQLite local à 0 ms de latence. Les caissiers encaissent sans aucun ralentissement.

🛡️ Standard Caisse Multi-Postes Anti-Conflit

Chaque ordinateur possède son propre identifiant de poste (C1, C2...). Deux caissiers déconnectés d'Internet peuvent encaisser en même temps sans jamais créer de doublon de reçu.

⚖️ Norme Comptable & Régulation Anti-Fraude (Duplicatas)

Impossible de sortir un faux reçu en cachette. Le premier tirage est certifié ORIGINAL, et toute réimpression ultérieure est automatiquement estampillée DUPLICATA N° X avec date, heure et nom de l'opérateur.

🔄 Synchronisation Asynchrone Sécurisée (Cloud Supabase)

Dès que la connexion Internet est détectée, le logiciel synchronise silencieusement en arrière-plan toutes les données vers la base Cloud de l'administration sans perturber le travail de l'utilisateur.

3. Initialisation & Pilote de l'Imprimante Thermique (Xprinter POS-80)

Pour que l'imprimante thermique 80 mm imprime à la vitesse maximale avec le massicot (coupe automatique) et sans caractères chinois sur les accents français, deux méthodes simples sont à votre disposition :

✨ Nouveauté v1.1.1 (Option intégrée) : L'administrateur peut désormais initialiser ou réparer la connexion de l'imprimante thermique directement en 1 clic depuis l'application, avec détection automatique de l'état actuel.

Étape 1 : Branchement physique

Branchez le câble USB de l'imprimante sur le PC, insérez le rouleau de papier thermique 80 mm (face thermique vers la tête) et allumez l'imprimante.

Étape 2 (Méthode Recommandée) : Initialisation en 1 clic depuis le LMS

Connectez-vous en tant qu'Administrateur, ouvrez la page Paramètres $\rightarrow$ section "Imprimante Thermique" :
• Si l'imprimante n'est pas configurée : Cliquez sur "Initialiser l'imprimante POS-80 (Automatique)".
• Si elle est déjà installée : Un badge vert indique qu'elle est prête. En cas de changement de prise USB, un bouton "Réinitialiser / Réparer" réaffecte automatiquement le bon port USB.
• Confirmez l'autorisation administrateur Windows (UAC) lorsqu'elle s'affiche.

Étape 2 bis (Méthode Manuelle Alternative) : Via le script autonome

Faites un clic droit sur le fichier installer-xprinter.bat situé dans tools/printer/ et choisissez "Exécuter en tant qu'administrateur". Le script vérifie l'état actuel et configure le pilote générique.

Étape 3 : Test d'impression

Dans la section "Imprimante Thermique" des Paramètres, cliquez sur "Tester l'impression (Ticket Test)". Un ticket test avec le logo du Lycée, les accents français nets et la découpe massicot sort immédiatement.

Script d'installation autonome (installer-xprinter.ps1) 
# Configuration de l'imprimante POS-80 avec pilote Generique Texte
Add-PrinterDriver -Name "Generic / Text Only" -ErrorAction SilentlyContinue
$port = (Get-CimInstance Win32_PnPEntity | Where-Object { $_.Service -eq "usbprint" }).DeviceID ? "USB001" : "USB001"
Add-Printer -Name "POS-80" -DriverName "Generic / Text Only" -PortName "USB001" -ErrorAction SilentlyContinue
Write-Host "Imprimante POS-80 configuree avec succes pour le LMS !"

Résolution des Conflits de Ports Imprimante (ex: Nicon/Canon + Xprinter POS-80)

Symptôme : Le câble USB de la Xprinter POS-80 est branché, Windows émet le signal sonore de connexion, le statut indique « Connecté », mais aucun ticket ne sort lors du test ou de l'impression.

Explication Technique : Lorsqu'un PC possède déjà une autre imprimante USB (ex: Canon ou Nicon), celle-ci s'approprie le port virtuel USB001. En branchant la POS-80, Windows lui assigne automatiquement USB002 ou USB003. Si le logiciel ou Windows envoie les tickets sur USB001, le flux thermique est envoyé à la mauvaise imprimante ou bloqué dans la file d'attente Windows.

Méthode 1 : Réparation Automatique en 1 Clic (Recommandée)

  1. Ouvrez le logiciel LMS et rendez-vous dans Paramètres $\rightarrow$ section Imprimante Thermique POS-80.
  2. Cliquez sur le bouton « Auto-détecter port USB (Conflit Nicon) ».
  3. Le logiciel scanne tous les ports USB d'impression disponibles, identifie le canal actif de la Xprinter et reconfigure automatiquement Windows sans aucune saisie technique.

Méthode 2 : Vérification Manuelle sous Windows

  1. Ouvrez le Panneau de configuration Windows $\rightarrow$ Périphériques et imprimantes.
  2. Faites un clic droit sur l'imprimante POS-80 et sélectionnez Propriétés de l'imprimante.
  3. Rendez-vous dans l'onglet Ports.
  4. Repérez quel port USB est coché. Si USB001 est coché mais ne répond pas, cochez USB002 (ou USB003) puis cliquez sur Appliquer.
  5. Cliquez sur Imprimer une page de test : le ticket sortira instantanément.
Fiche 7.2

Protocole de Désinfection : Virus des Raccourcis USB (PC lent & Clés infectées)

Symptômes : Les dossiers d'une clé USB insérée se transforment en raccourcis (.lnk), le PC 1 ralentit fortement et la mémoire vive (RAM) est saturée par des processus fantômes.

Origine : Il s'agit du ver Windows Shortcut Worm (exécuté par wscript.exe). Il masque vos vrais documents et lance un script malveillant en boucle, ce qui épuise les ressources du processeur et perturbe les impressions.

Procédure de Nettoyage et Restauration Immédiate :

  1. Arrêter le script parasite en mémoire :
    Appuyez sur Ctrl + Maj + Échap pour ouvrir le Gestionnaire des tâches. Cherchez wscript.exe ou Windows Based Script Host, faites clic droit puis Fin de tâche.
    Ou en invite de commandes (CMD) : taskkill /f /im wscript.exe
  2. Révéler les vrais fichiers cachés sur la clé USB :
    Si votre clé USB porte la lettre E:, ouvrez l'Invite de commandes (CMD) et tapez :
    attrib -h -r -s /s /d E:\*.*
    Vos vrais dossiers réapparaîtront immédiatement sur la clé USB sans aucune perte.
  3. Supprimer les faux raccourcis :
    Sur la clé USB, supprimez manuellement tous les fichiers de type « Raccourci » (taille ~1 Ko) portant le nom de vos anciens dossiers.
  4. Désactiver le démarrage automatique du virus :
    Dans le Gestionnaire des tâches $\rightarrow$ onglet Démarrage, désactivez tout élément suspect pointant vers wscript.exe ou un fichier .vbs situé dans AppData\Roaming ou Temp.
Fiche 7.3

Arrêt d'Urgence de l'Impression & Vidage de la File Spooler (Nettoyage Express)

Symptôme : L'imprimante s'emballe, fait défiler du papier thermique en continu, ou un ticket corrompu reste coincé dans Windows après un mauvais paramétrage de port ou une coupure électrique. Même en éteignant l'imprimante, le ticket recommence à sortir au rallumage.

Fonction du Bouton d'Urgence : Le bouton rouge « Arrêter & Vider la file (Urgence) » (dans Paramètres $\rightarrow$ Imprimante Thermique) ordonne au Spooler Windows de détruire immédiatement tous les travaux en attente (WMI CancelAllJobs()) et réinitialise l'état de l'imprimante.

Procédure Immédiate :

  1. Ouvrez Paramètres $\rightarrow$ section Imprimante Thermique & Poste de Caisse.
  2. Cliquez sur le bouton rouge « 🛑 Arrêter & Vider la file (Urgence) ».
  3. Confirmez le dialogue de validation. Le logiciel annule instantanément tous les travaux bloqués dans Windows, purge le flux de données brutes ESC/POS et sort l'imprimante du mode hors-ligne.
  4. Règle de sécurité : Tous les tickets non imprimés qui se trouvaient dans la file sont considérés comme annulés et non effectués. Aucun ticket fantôme ne sortira ultérieurement. Vous pouvez relancer vos impressions propres sans aucun risque.

Surveillance de Synchronisation : Comprendre le Point Rouge & Statut Cloud

Indicateur Visuel : Un point rouge clignotant ou un badge orange/rouge dans la barre d'en-tête signale que des écritures locales (nouveaux paiements, inscriptions) sont enregistrées en local mais n'ont pas encore pu être acheminées vers le Cloud Supabase.

Sérénité Totale (Zéro Perte de Données) : Grâce à l'architecture Local-First du LMS, 100% de vos données sont stockées de façon inaltérable dans la base locale SQLite. Les secrétaires peuvent continuer à encaisser et imprimer des reçus sans interruption, même en coupure totale d'Internet.

Que faire si le voyant rouge persiste avec une connexion Internet active ?

  1. Cliquez sur le badge de statut de synchronisation en haut de l'écran ou allez dans Paramètres.
  2. Cliquez sur « Réparer / Forcer la Synchronisation ».
  3. Le moteur v1.1.10 réinitialise automatiquement le curseur de synchronisation, nettoie les données selon le schéma Cloud Supabase et renvoie toutes les écritures en attente.
  4. Dès que l'envoi est confirmé par le Cloud, le voyant passe instantanément au vert fixe (« Synchronisé »).
Fiche 7.5

Centre de Contrôle des Doublons : Conflits de Paiement C1 vs C2 & Fiches Élèves

Scénario : La secrétaire sur le Poste 1 a encaissé des écolages. Ne les voyant pas encore sur le Poste 2 en raison d'un délai réseau, l'opératrice du Poste 2 a ré-encaissé les mêmes sommes pour les mêmes élèves, créant des paiements concurrents.

Protection Intégrée (Module Doublons) : Le logiciel intègre un module intelligent d'arbitrage accessible dans le menu latéral $\rightarrow$ « Doublons » (ou dans Paramètres). Il analyse les concordances et propose une résolution guidée sans risque comptable.

Comment arbitrer un doublon en toute sécurité :

  1. Ouvrez le Gestionnaire de Doublons dans le menu de gauche.
  2. L'écran affiche les conflits détectés : même élève, même mois d'écolage, montants identiques ou rapprochés émis sur C1 et C2.
  3. Comparez les deux tickets côte à côte (dates, heures, opérateurs, montants).
  4. Cliquez sur « Conserver Reçu C1 » ou « Conserver Reçu C2 » : le reçu doublon est annulé proprement avec trace comptable complète dans settings_history.
  5. Si le parent a volontairement payé deux tranches réelles, cliquez sur « Conserver les deux (Valide) » pour lever l'alerte.

Fiche 7.8

Début d'Exercice (Personnel & Salaires) : Fonctionnement Mensuel & Questions d'Analyse

Contexte : Dans le module Salaires & Impayés, un bandeau d'alerte jaune signale les employés qui n'ont pas encore de « Début de paie (Exercice) » défini dans leur fiche. Cette fiche détaille l'emplacement du champ, la raison du format mensuel (AAAA-MM) et les questions clés à clarifier avec l'établissement.

📍 Où se trouve le réglage dans le logiciel ?
1. Rendez-vous dans Personnel ➔ Liste du personnel.
2. Cliquez sur l'icône Modifier (crayon ✏️) sur la ligne de l'employé concerné.
3. Faites défiler la page jusqu'à la section « Informations professionnelles » (située juste au-dessus de Rémunération).
4. Le champ s'intitule « Début de paie (Exercice) » (sélecteur mois/année ex: 2025-09) avec l'instruction « Ignorer le passif avant ce mois ».
5. Cliquez sur Enregistrer en bas de page.

1. Pourquoi le format mensuel (AAAA-MM) sans mentionner le jour précis ?

✅ Avantages du Format Mensuel (AAAA-MM)
  • Unité de compte globale : En comptabilité scolaire malgache, les salaires et impayés sont calculés par mois civil entier (ex: Salaire de Septembre, Salaire d'Octobre).
  • Verrou anti-faux impayés : Indiquer 2025-09 ordonne au logiciel de démarrer l'historique en Septembre 2025 et d'ignorer tout le passé des années antérieures.
  • Aucune ambiguïté de prorata : Évite de générer par erreur des demi-salaires ou fractions de salaires non souhaitées.
  • La date exacte au jour le jour existe déjà : C'est le champ « Date d'embauche » (AAAA-MM-JJ) réservé au contrat et à l'ancienneté.
⚠️ Risques d'un Format au Jour Précis (AAAA-MM-JJ)
  • Problème du prorata automatique : Si on saisit le 15/09/2025, le système doit-il payer un demi-salaire, compter les jours ouvrés ou 15/30e ?
  • Incompatibilité avec les salaires fixes : Les contrats d'école prévoient un forfait mensuel ; les ajustements de premier mois se font généralement de gré à gré ou via les heures réelles pointées.
  • Lourdeur de saisie : Oblige le gestionnaire à chercher un jour calendaire précis au lieu de simplement pointer le mois de rentrée.

9. Foire Aux Questions (FAQ) & Bonnes Pratiques Caissiers

❓ Que faire si l'imprimante ne répond pas ou n'imprime rien ?

1. Vérifiez que l'imprimante est allumée (voyant bleu allumé) et que le câble USB est branché.
2. Allez dans Paramètres -> "Imprimante Thermique" et cliquez sur "Tester l'impression".
3. Si nécessaire, réexécutez installer-xprinter.bat en mode Administrateur.

❓ Que faire si la connexion Internet coupe pendant plusieurs jours ?

Rien de particulier ! Vous pouvez continuer d'inscrire des élèves, d'enregistrer des paiements et d'imprimer des reçus normalement. Dès que la connexion revient, le logiciel se synchronisera tout seul sans aucune action de votre part.

❓ Comment un parent peut-il obtenir un duplicata si son reçu est perdu ?

Rendez-vous sur la fiche de l'élève (onglet Finance), repérez le paiement concerné et cliquez sur le bouton "Ticket". Le logiciel sortira automatiquement un Duplicata Certifié sans modifier la comptabilité originale.
